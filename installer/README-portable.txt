PT. BPR Bank Bulungan — Aplikasi Undian (versi portable / tanpa install)
==========================================================================

CARA PAKAI
1. Extract SEMUA isi zip ini ke satu folder (jangan cuma file .exe-nya).
2. Jalankan BPR_Bank_Bulungan.exe dari folder hasil extract.

PENTING: JANGAN PISAHKAN FILE
File .exe butuh file-file pendamping di folder yang sama (flutter_windows.dll,
sqlite3.dll, folder data/, dsb). Kalau .exe-nya dicopy keluar sendirian,
aplikasi tidak akan jalan.

SYARAT: Microsoft Visual C++ Redistributable (x64)
Aplikasi butuh library ini. Kebanyakan PC sudah punya; kalau aplikasi
diklik tapi tidak terjadi apa-apa (crash diam-diam), install dulu:
  https://aka.ms/vs/17/release/vc_redist.x64.exe
Lalu restart PC dan coba lagi.

Catatan: versi installer (PT-BPR-Bank-Bulungan-Setup.exe) memasang library
ini secara otomatis bila belum ada — pakai installer bila ragu.
